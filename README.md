# Student Task Manager

## Project Description

Student Task Manager is a simple web-based application that helps students manage their daily tasks. Users can add, view, complete, delete, and search for tasks through an easy-to-use interface.

## Git Workflow

The project was developed using Git and GitHub for version control and collaboration.

The basic workflow followed was:

1. Create and clone the GitHub repository.
2. Create branches for development.
3. Make changes to the project files.
4. Stage and commit changes.
5. Push changes to GitHub.
6. Create and review Pull Requests.
7. Merge completed changes into the main branch.
8. Create a version tag for the final release.

## Branches

- `main` — Contains the stable version of the project.
- `feature/*` — Used for developing new features or making specific changes.
